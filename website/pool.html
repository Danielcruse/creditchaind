OUTERNET Pool

Every token on this network - native (ETHTEST, USDCTEST) or developer-registered - trades against CCT through a constant-product pool, the same pricing model a real DEX uses. Pick a function below.

💧

Liquidity Pool

Add or remove liquidity from any pool - deposit CCT + a token to earn LP shares, or withdraw your share back out.
⇆

Swap

Trade one token for another - a single pool swap, or a universal swap between any two tokens routed through CCT.
📈

Price Chart

Live price chart for every token that trades on OUTERNET - see how a pool's price has moved from real trading activity.
📋

Order Book

Buy and sell CCT against ETHTEST or USDCTEST at your own price - real bid/ask orders set the market price, not a pool.
💻

Developers

Register a new token and seed its liquidity pool so it becomes tradeable across the whole network.

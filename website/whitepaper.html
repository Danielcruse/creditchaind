OUTERNET Testnet and Early Access Program

Vision

The goal is not simply to launch a website, but to create a working prototype where early users can interact with the CreditChain ecosystem.

The first phase is to onboard one hundred test users who can:

  • Register accounts
  • Receive wallets
  • Interact with a test blockchain
  • Build reputation
  • Participate in governance
  • Test lending and staking mechanisms

Admin - Treasury

Admin actions are authorized by a real signature from the network's configured admin wallet - the same Ed25519 signing every ordinary wallet action already uses, not a shared secret. Log in with the CreditChain wallet that's been configured as the admin wallet (via ADMIN_WALLET_ADDRESS) and every action below signs with that wallet's own key. This page carries no authority of its own - every check happens server-side, independently, on every node.

Admin - Treasury

Admin actions are authorized by a real signature from the network's configured admin wallet - the same Ed25519 signing every ordinary wallet action already uses, not a shared secret. Log in with the CreditChain wallet that's been configured as the admin wallet (via ADMIN_WALLET_ADDRESS) and every action below signs with that wallet's own key. This page carries no authority of its own - every check happens server-side, independently, on every node.

ETH + BTC Custodial Signers - AWS Credentials

Sets the AWS IAM credentials the ETH and BTC custodial KMS signers both need to move off their insecure in-memory fallback signers (see api/eth_signer.go and api/vault_btc_signer.go) - one credential activates both, since they use the identical secp256k1 KMS key type. Required before any real ETH or BTC vault custody can run production-grade on mainnet. This is write-only: nothing on this site, including this page, ever reads these values back. Saving here only writes the credentials to a restricted file on the server - it does not take effect until the service is restarted, since a running process can't pick up new environment variables on its own. Make sure the IAM policy attached to this credential allows kms:CreateKey, kms:GetPublicKey, and kms:Sign broadly (not scoped to one existing key ARN only) - the BTC signer creates its own fresh KMS key the first time it's used, the same way the ETH signer already did.

Genesis Pools

Withdraw from one of the 4 genesis pools with no controlling keypair of their own (Validator Reward, Ecosystem Development, Governance Treasury, Community Incentives) - gated by the admin wallet's signature, same as everything else on this page. Foundation Treasury is not one of these - it's managed above, via its own real address.

These pools (and the Foundation Treasury address above) only have a real balance once the one-time genesis allocation below has been run. It mints 1,000,000,000 CCT total in a single action - 400M to Validator Reward, 250M directly to the Foundation Treasury address currently configured above, 150M to Ecosystem Development, 100M to Governance Treasury, 100M to Community Incentives. This can only ever fire once (a second attempt is a safe no-op) - make sure the Foundation Treasury address above is set correctly BEFORE running this, since that's where its 250M lands.


Testnet CCT Faucet (Admin)

Mints new testnet CCT directly to any address - the operator-only counterpart to the public 100-CCT one-time faucet, for seeding a wallet with enough to stake/register as a validator. Testnet only: this card is hidden entirely while Mainnet is selected, and the button itself refuses to submit if the network switches underneath you.


Balance Recovery

Moves a balance an address already holds to a different address, without needing that address's own signature - for exactly one situation: funds landed at the wrong address due to a bug (e.g. an internal transfer credited to an unresolved address instead of the recipient's real one) and need a one-time correction. This can only move value that's already there - it never creates new supply. Gated by the admin wallet's signature, same as everything else on this page.


Normalize Un-Normalized ETH_CCC1/USDC_CCC1 Balance

One-off migration tool for exactly one situation: a balance minted under a mixed-case (checksummed) address key by a bug that's since been fixed - permanently invisible to the normal balance endpoint (which always looks up the lowercase-normalized form), even though the value is genuinely on the ledger. Enter the address exactly as it's actually stored (the wrong-case form) - this reads the raw balance at that exact key and moves it to that same address's properly normalized (lowercase) key. Safe to run against an address that's already normalized or already empty - it just no-ops.


Refund a Stuck Vault Release Burn

One-off remediation for a vault release approval that burned a user's ETH_CCC1/USDC_CCC1 balance but can never actually deliver anything - either a permanently stuck bridge-validator signature, or a release amount the flat gas fee zeroed out entirely. Only works on an approval that is still PENDING (never actually executed on-chain, so the real ETH/USDC never left the vault) - refuses outright once RELEASED. Refunds the full original burned amount (release + fee) back to the burner's own real self-custodial address, and marks the approval REFUNDED so it can never be signed, relayed, or refunded again.


Sweep Vault Signing Key ETH → Relayer

One-off fix for exactly one mistake: real ETH accidentally sent to the vault release-approval signing key's address (it only ever produces signatures, never pays gas, so ETH sent there is otherwise stuck) instead of the relayer's address. Moves everything above the gas cost of this sweep itself to the currently configured relayer. Safe to click even if there's nothing to sweep - it just reports so.

CCT Decimal Migration (one-time)

Converts every CCT balance from the old whole-unit ledger into the new 18-decimal ledger. This is a one-way, whole-network mutation - it can only ever run once (a second attempt is a safe no-op). Every CCT balance will read as 0 on this network until this is run.


Validator Join Requests

Submitted from the Validator page's "Request to Join" form (website/validator.html). This just tracks who's asked, so "Mark Handled" once you've actually reached out to them off-platform.
